# Projects-Sederhana-Python

Ini adalah project kecil-kecilan yang saya bikin setelah mempelajari bahasa Python.  
> 💡 **Catatan:** Project ini dibuat murni hasil latihan tanpa AI.

---

## 📁 Daftar Project di Repositori Ini:

### 1. Project Game Tebak Angka
Di sini Anda akan bermain game dengan menebak angka dari 1-100. Semakin dekat Anda menebak angkanya, akan ada petunjuk (hint) untuk menebaknya.

### 2. Project Membuat Tabel Matematika
Di project ini Anda bisa membuat tabel angka otomatis dengan operasi matematika yang ada, yaitu:
- Pertambahan (`+`)
- Pengurangan (`-`)
- Perkalian (`*`)
- Pembagian (`/`)

*Sesuai dengan range angka yang Anda tentukan sendiri.*

### 3. Project Game Tebak Kata
Project ini mengajak Anda bermain menebak kata umum dari kategori yang disediakan:
- Buah-buahan
- Sayur-sayuran
- Bahasa Pemrograman

Berbeda dengan game tebak angka, di sini Anda memiliki **7 kali kesempatan** untuk menebak kata dan tidak ada petunjuk (*hint*), jadi pikirkan kemungkinan kata yang dimaksud dengan cermat!
