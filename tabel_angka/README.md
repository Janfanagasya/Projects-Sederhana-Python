# 📊 Generator Tabel Matematika (Python CLI)

Aplikasi berbasis Command Line Interface (CLI) untuk membuat dan menampilkan tabel matematika interaktif berdasarkan operasi dasar dan rentang angka yang ditentukan oleh pengguna.

---

## ⚙️ Fitur Utama
- **Operasi Matematika Lengkap:**
  - Penjumlahan (`+`)
  - Pengurangan (`-`)
  - Perkalian (`*`)
  - Pembagian (`/`)
- **Fleksibel:** Rentang (range) angka awal dan akhir dapat ditentukan sendiri oleh pengguna.
- **Struktur Modular:** Kode dipisah secara terorganisir ke dalam modul operasi dan tampilan (*view*).

note: untuk pengurangan mungkin konsep nya kurang jelas jadi tolong dimaklumin.
---

## 🚀 Cara Menjalankan Program
Pastikan Python sudah terinstal di komputer Anda, lalu jalankan perintah berikut di terminal/Command Prompt:

```bash
python main.py
