# 🔤 Game Tebak Kata (Python CLI)

Aplikasi permainan tebak kata interaktif berbasis Command Line Interface (CLI) menggunakan fitur-fitur modern Python.

---

## 🎮 Cara Kerja Game
1. Pilih **kategori kata** yang ingin dimainkan:
   - 🍎 **Buah-buahan**
   - 🥦 **Sayur-sayuran**
   - 💻 **Bahasa Pemrograman**
2. Program akan memilih satu kata acak dari kategori yang dipilih.
3. Anda memiliki **7 kali kesempatan** untuk menebak kata tersebut.
4. Berbeda dengan game tebak angka, game ini **tidak memberikan petunjuk (*hint*)**, jadi tebaklah kata dengan cermat!

---

## 🚀 Cara Menjalankan Program
Pastikan Python sudah terinstal di komputer Anda, lalu jalankan perintah berikut di terminal/Command Prompt:

```bash
python game.py
