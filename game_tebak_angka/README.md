# 🎲 Game Tebak Angka (Python CLI)

Aplikasi game sederhana berbasis Command Line Interface (CLI) untuk menebak angka rahasia secara interaktif.

---

## 🎮 Cara Kerja Game
1. Program akan memilih angka acak antara **1 hingga 100**.
2. Anda diminta untuk memasukkan tebakan angka.
3. Program akan memberikan petunjuk (*hint*):
   - **Angak Lebih Besar**: Jika angka tebakan Anda lebih kecil dari jawaban.
   - **Angak Lebih Kecil**: Jika angka tebakan Anda lebih besar dari jawaban.
   -**Angka Sudah dekat**: Apabila angka tebakan Anda sudah mendekati jarak 5 angka dari jawaban
4. Permainan selesai setelah Anda berhasil menebak angka dengan benar!

---

## 🚀 Cara Menjalankan Program
Pastikan Python sudah terinstal di komputer Anda, lalu jalankan perintah berikut di terminal/Command Prompt:

```bash
python main.py
